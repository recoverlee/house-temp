# 집안 온도계

오후 6~8시 거실 폰이 대화를 듣고, 분위기를 온도(14~30°C)와 한 줄 코멘트로 바꿔 줘요. 퇴근 전에 내 폰에서 확인해요.

- 녹음 파일은 만들지 않아요. 음성은 크롬의 음성 인식으로 글자가 되고, 10분마다 분석한 뒤 글자는 버려요.
- 저장되는 것은 시각, 온도, 분위기 키워드뿐이에요.
- 분석은 브라우저 안의 규칙 기반이라 비용이 들지 않아요. (`analyzer.js`의 단어 목록으로 조절)
- 음성 인식은 크롬 서비스가 처리하므로 음성이 Google 서버로 전송될 수 있어요.

## 1. 배포 (GitHub Pages, 무료)

저장소 Settings > Pages > Branch를 `main` / `/ (root)`로 설정하면 `https://<계정>.github.io/<저장소>/` 주소가 생겨요.

## 2. 폰끼리 동기화 (Firebase, 무료)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들어요.
2. Build > Firestore Database > 데이터베이스 만들기 (프로덕션 모드, 서울 `asia-northeast3`).
3. Firestore > 규칙 탭에 `firestore.rules` 내용을 붙여넣고 게시해요.
4. 프로젝트 설정 > 내 앱 > 웹 앱(`</>`)을 등록하고, 나오는 `firebaseConfig` 값을 `config.js`의 `firebase`에 붙여넣어요.
5. 커밋하고 푸시하면 반영돼요.

설정 전에는 그 기기 안에만 저장돼서, 화면 확인용으로만 쓸 수 있어요.

## 3. 사용

1. 내 폰에서 주소를 열고 "새 집 코드 만들기"를 눌러요. 설정에서 "다른 폰용 링크 복사"로 링크를 거실 폰에 보내요.
2. 거실 폰(안드로이드 크롬)에서 링크를 열고 "거실 폰" 탭 > "시간이 되면 자동으로 시작"을 켜요. 처음 한 번 마이크를 허용해요.
3. 거실 폰은 충전기에 꽂고 화면을 켜 둬요. 화면이 꺼지거나 크롬이 백그라운드로 가면 인식이 멈춰요.
4. 내 폰의 "퇴근 전 확인" 탭에서 온도, 코멘트, 최근 7일 그래프를 봐요.

## 한계

- 집 코드를 아는 사람은 기록을 읽을 수 있어요. 코드는 24자리 무작위 문자열이라 링크를 공유하지 않으면 안전하지만, 계정 로그인 방식은 아니에요.
- 규칙 기반 분석이라 농담이나 반어를 구분하지 못해요. 온도는 참고용이에요.
- iPhone 사파리는 음성 인식이 불안정해서 거실 폰으로는 권하지 않아요. 확인용으로는 잘 열려요.
